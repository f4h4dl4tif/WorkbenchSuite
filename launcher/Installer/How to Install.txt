How to install Workbench
========================

Workbench is the launcher for the Workbench Suite: it installs, updates and
opens every tool in the suite. Requires macOS 14 Sonoma or later. Runs on
Apple Silicon and Intel Macs.

Workbench isn't notarized by Apple, so on a new Mac macOS blocks it the first
time. Pick ONE of the two ways below, and use the Terminal fixes if it fails.


OPTION A: Installer package (Workbench-x.x.x.pkg)  <- recommended
-----------------------------------------------------------------
1. Double-click Workbench-x.x.x.pkg.
2. If macOS says it "can't be opened" or "could not verify" it: click Done,
   open System Settings > Privacy & Security, scroll to Security and click
   "Open Anyway" next to Workbench-x.x.x.pkg. Enter your password.
3. Follow the installer. Workbench is installed in Applications.


OPTION B: Disk image (Workbench-x.x.x.dmg)
------------------------------------------
1. Open the .dmg and drag Workbench onto the Applications folder.
2. Open Workbench from Applications. If macOS blocks it, click Done (don't
   move it to the Bin), then System Settings > Privacy & Security >
   "Open Anyway".


IF IT STILL FAILS: Terminal commands
------------------------------------
Open Terminal (Applications > Utilities > Terminal), paste a command, press
Return and type your Mac password when asked (nothing shows as you type).

1. The installer package won't open. Install it from Terminal instead
   (change the path if the file isn't in Downloads):

       sudo installer -pkg ~/Downloads/Workbench-*.pkg -target /

2. Workbench is installed but won't open, or macOS says it is "damaged":

       sudo xattr -cr /Applications/Workbench.app && open /Applications/Workbench.app

3. "Open Anyway" doesn't appear, or the .pkg / .dmg itself is blocked:

       xattr -c ~/Downloads/Workbench-*

   then double-click the file again.

4. A tool installed by Workbench won't open or is reported "damaged"
   (replace Wattline with the tool's name):

       sudo xattr -cr /Applications/Wattline.app

5. Workbench says it can't write to /Applications: open Workbench >
   Settings and choose "~/Applications (just me)", or fix permissions:

       sudo chown -R "$USER" /Applications/<Tool>.app

6. Check the Mac is new enough (must say 14 or higher):

       sw_vers -productVersion

7. Reset Workbench's saved settings and GitHub token:

       defaults delete app.workbenchsuite.launcher
       security delete-generic-password -s app.workbenchsuite.launcher.github


AFTER INSTALLING
----------------
Open Workbench, pick a tool and click Install. Tools that are already
installed show Open, and Update when a newer release is on GitHub.
Press Command-R to check for updates at any time.

To uninstall: drag /Applications/Workbench.app to the Bin. Tools you
installed with it stay installed.
