01/ The lineup

Every tool, one place.

Each tool is its own open-source repo with its own releases. Download one directly, or let the launcher handle installs and updates.

02/ Principles

Built the way Mac apps should be.

01

Open source

Every tool is MIT licensed. Read the code, fork it, ship your own build.

02

Native, not wrapped

SwiftUI and AppKit, no Electron and no web views. Small downloads, low memory, real Mac behaviour.

03

Local-first

Your files and data stay on your Mac. No accounts, no cloud sync you didn't ask for, no tracking.

04

On-device intelligence

Where a tool uses AI, it runs on Apple's on-device models. Nothing is uploaded.

05

Focused

Each app does one job well, instead of one app trying to do everything.

06

Free forever

No subscriptions and no trials. Install what you need and keep it.

03/ The launcher

Install once. Stay current.

Workbench is the recommended way to get the suite. It reads each tool's latest GitHub release and does the rest.

  • One-click install into Applications from each tool's release
  • Shows what's installed and which tools have updates
  • Update everything at once, open or uninstall any tool
  • New tools show up automatically as the suite grows
